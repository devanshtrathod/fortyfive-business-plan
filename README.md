# FortyFive Business Plan

Interactive business plan for FortyFive: courses and an honest tutor marketplace for IB Diploma students in India.

## Live site

Once GitHub Pages is enabled, the site is available at:

**https://devanshtrathod.github.io/fortyfive-business-plan/**

### Enable GitHub Pages (one-time)

1. Open this repository on GitHub: https://github.com/devanshtrathod/fortyfive-business-plan
2. Go to **Settings** → **Pages** (left sidebar)
3. Under "Build and deployment":
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes. The site will be live at the URL above.
